<h3> 🏆 Challenges </h3>

Você pode apresentar o resultado tanto no **console** quanto em um **alerta** no navegador.

✪ Challenge 1. Crie um script que exiba a mensagem "Hello World!" em um alerta no navegador. [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/01) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/01/).<br>

✪ Challenge 2. Crie um script que declare duas variáveis e exiba o resultado da soma entre elas. [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/02) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/02/).<br>

✪ Challenge 3. Crie um script que declare uma variável e verifique se o seu valor é um número. Se for, exiba a mensagem "É um número", caso contrário, exiba a mensagem "Não é um número". [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/03) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/03/).<br>

✪ Challenge 4. Crie um script que declare uma variável e verifique se o seu valor é uma string. Se for, exiba a mensagem "É uma string", caso contrário, exiba a mensagem "Não é uma string". [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/04) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/04/).<br>

✪ Challenge 5. Crie um script que declare uma variável e verifique se o seu valor é um booleano. Se for, exiba a mensagem "É um booleano", caso contrário, exiba a mensagem "Não é um booleano". [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/05) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/05/).<br>

✪ Challenge 6. Crie um script que declare duas variáveis e exiba o resultado da subtração entre elas. [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/06) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/06/).<br>

✪ Challenge 7. Crie um script que declare duas variáveis e exiba o resultado da multiplicação entre elas. [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/07) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/07/).<br>

✪ Challenge 8. Crie um script que declare duas variáveis e exiba o resultado da divisão entre elas. [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/08) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/08/).<br>

✪ Challenge 9. Crie um script que declare uma variável e verifique se o seu valor é um número par. Se for, exiba a mensagem "É um número par", caso contrário, exiba a mensagem "Não é um número par". [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/09-10) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/09-10/).<br>

✪ Challenge 10. Crie um script que declare uma variável e verifique se o seu valor é um número ímpar. Se for, exiba a mensagem "É um número ímpar", caso contrário, exiba a mensagem "Não é um número ímpar". [Repo](https://github.com/MichelleCordeiro/rocketseat-explorer/tree/main/stage-01-04-intensivao/desafios-javascript/09-10) and see it online [here](https://MichelleCordeiro.github.io/rocketseat-explorer/stage-01-04-intensivao/desafios-javascript/09-10/).<br>
